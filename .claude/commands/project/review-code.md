コードレビューコマンドです。静的解析と定性レビューをセットで実行します。

## Step 1: 対象ファイルの収集

```bash
find . -name "*.py" | grep -v -E "(\.git|__pycache__|\.pytest_cache)/" | sort
```

## Step 2: 静的解析の実行

```bash
python3 -m black --check . 2>/dev/null | tail -10
```

## Step 3: ライセンスヘッダー確認

`/project:license-check` と同等のチェックを実行し、ヘッダー欠けファイルがあれば一覧表示してください。

## Step 4: ドキュメントコメントの確認

docstring のない `def` / `class`（`__` 始まり・`test_` ファイルは除外）を検出してください。

## Step 5: 定性レビュー

収集したソースファイルを読み込み、以下の観点でレビューしてください：

- **命名規則**: Pythonのコンベンション（snake_case）に従っているか
- **コード構造**: 関数が単一責任の原則に従っているか（目安: 50行以上の関数は要確認）、重複コードがないか
- **セキュリティ**: `QIITA_TOKEN` がハードコード・ログ出力されていないか、外部入力（記事本文・タグ等）が適切にサニタイズされているか
- **AGENT_MASTER_PLAN.md との整合性**: APIエンドポイント仕様・データモデルに沿っているか

## Step 6: 結果の表示

```

### ドキュメントコメント
- ✅ 全関数 OK / ⚠️ 未記入: N件

### 定性レビュー

**🟢 良い点**
- ...

**🟡 改善提案**
- path/to/file.py L42: （指摘内容）

- （秘密情報の露出など重大な問題があれば）

---
STATUS: ✅ 問題なし / ⚠️ 軽微な指摘あり / 🔴 要対応あり
NEXT: （対応が必要な場合は修正方針を記載。なければ「なし」）
```
