ライセンスヘッダーチェックコマンドです。全Pythonソースファイルにライセンスヘッダーが含まれているか検証します。

## Step 1: 対象ファイルの収集

```bash
find . -name "*.py" | grep -v -E "(\.git|__pycache__|\.pytest_cache)/" | sort
```

## Step 2: ヘッダーの確認

各ファイルの先頭10行を読み込み、`License` / `license` / `Copyright` / `copyright` のいずれかの文字列を含む `"""` ブロックがあるかチェックしてください。

## Step 3: 結果の表示

```
## ライセンスヘッダーチェック結果

### ✅ ヘッダーあり（N ファイル）
- src/main.py
- ...

### ❌ ヘッダーなし（N ファイル）
- src/xxx.py  ← 要対応

合計: X / Y ファイルにヘッダーあり
```

## Step 4: 修正の提案

ヘッダーなしファイルが存在する場合、`CLAUDE.md` のライセンスヘッダーテンプレートを参照し、ユーザーの承認を得てから追加してください。

`{{LICENSE}}` などのプレースホルダーが未置換の場合は、`/project:init` を先に実行するよう案内してください。
